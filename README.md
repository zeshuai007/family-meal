# 家味 · 家庭点菜系统（Family Kitchen）

为家中孕妇（孕妈妈）准备的家庭内部点菜系统：家人通过手机 / 平板 / 电脑查看菜单、在线点三餐（早/午/晚），婆婆查看当天点好的菜并按做法下厨，菜做好后上传成品图、家人评分点评，形成温馨的记录。

## ✨ 功能一览

- **📱 三端自适应**：手机（竖/横屏）、平板、桌面电脑均有舒适布局。
- **🍽 菜单馆**：每道菜包含 **菜品图片 / 主食材 / 配菜 / 配料调料 / 详细做法 / 适合时段 / 口味标签**。
- **🗓 每日三餐点菜**：任意日期切换（昨天/今天/明天…），早餐/午餐/晚餐三栏分别点菜，支持备注（例如“少盐”）。
- **🖼 成品图上传 + 评分**：每道菜可上传多张成品图、打 1-5 星、写点评，点评记录显示**评分人**、时间与所属餐次。
- **🔐 管理员权限**：菜品的新增 / 编辑 / 上下架 / 删除，家人的新增与管理员授权，均仅限管理员操作；首次登录需设置管理密码。
- **💾 持久化**：点菜记录、点评、菜单、家人信息全部保存在浏览器 `localStorage`，刷新不丢数据。
- **🎨 温暖居家美学**：陶土红 + 蜜橙 + 橄榄绿的暖色配色，柔和纸感底纹，衬线标题点缀，告别“AI 样板感”。

## 🚀 部署到 1panel 面板

### 方法 A：网站 → 创建静态站点（最简单、推荐）

1. **登录 1panel** → 左侧「网站」→「创建网站」
   - 类型：**静态网站**
   - 主目录：自定义，例如 `/www/wwwroot/family-meal`
   - 域名：填要使用的域名（例如 `meal.yourdomain.com`）；家庭内网用也可以稍后改 `hosts`
   - PHP 版本：**纯静态**
   - 其他保持默认 → 提交

2. **上传源码**
   用以下任一种方式把项目文件放到站点根目录（即上面的主目录）：
   - 方式一：1panel 内置「文件」管理，进入主目录，上传 `index.html`、`styles.css`、`app.js` 三个文件。
   - 方式二：`scp` 上传到服务器，然后 `mv` 到主目录。
   - 方式三：在服务器上 `git clone` 本项目后拷贝进去。

   目录最终应有：
   ```
   /www/wwwroot/family-meal/
   ├── index.html
   ├── styles.css
   └── app.js
   ```

3. **（可选）替换站点的 Nginx 配置**
   1panel → 网站 → 对应站点 → 「配置」→ 把 `nginx.conf` 中内容粘贴进去并保存（主要增加 gzip 与缓存策略）。默认的 1panel 静态站点也能工作，此步仅为优化。

4. **申请 / 配置 HTTPS（建议）**
   站点 → 「SSL」→ 选择 Let’s Encrypt 或上传自签证书；启用后可获得更好的浏览器兼容性（密码输入、剪贴板等）。

5. **访问**
   浏览器打开配置的域名（或服务器 IP + 端口）即可使用。手机端把域名发到家庭群，每个人都可以通过自己的浏览器打开。

> 🧷 关于“多端共享数据”的说明：
> 本项目为**纯前端**单页应用，数据默认保存在每个浏览器自己的 `localStorage` 中。如果家人希望“妈妈手机点的菜，婆婆那边也能看到”，后续升级到「多人共享」的方式有两种：
> - 方式一（最省事）：全家用同一台设备 / 同一浏览器访问，通过顶部「我是」切换身份，点菜与点评都写入同一份数据。
> - 方式二：接入轻量后端（推荐 1panel 中同步部署 **PocketBase / Supabase / 本地 SQLite + Node**），把当前 `app.js` 中的 `saveStore / loadStore` 改成调用后端 REST API。需要的话，我可以直接在当前工程基础上扩展出后端版本。

### 方法 B：1panel → Docker → 跑一个 Nginx 容器

1. 把项目放在宿主机目录如 `/opt/family-meal`，包含 `index.html / styles.css / app.js`。
2. 1panel → 容器 → 创建容器：
   - 镜像：`nginx:alpine`
   - 端口映射：宿主机 8080 → 容器 80（也可自定义）
   - 目录挂载：`/opt/family-meal` → 容器内 `/usr/share/nginx/html`（只读）
   - 网络：bridge
3. 启动容器后，访问 `http://服务器IP:8080` 即可。
4. 若需走域名 + HTTPS，在 1panel「网站」里做反向代理到 `127.0.0.1:8080` 并配 SSL。

## 🔑 使用说明（首启小贴士）

| 场景 | 操作 |
|---|---|
| 首次进入，谁是管理员？ | 默认家人「婆婆」是管理员。你可以先切到「婆婆」身份直接管理；或者点击右上角 **🔒 管理员登录**，首次会让你设置密码，设置完当前身份也会自动升级为管理员。 |
| 新增菜品 | 管理员身份 → 「管理台」→ 「＋ 新增菜品」；或「菜单馆」→「＋ 新增菜品」。 |
| 给家人授权 | 管理员身份 → 「权限」页面，勾选对应家人的「管理员」复选框即可。 |
| 婆婆今天做了一道菜，怎么记录？ | 在「今日三餐」点击对应菜下面的 **点评 🖋**，上传成品图、打星、写点评。 |
| 怎么看历史点评？ | 顶部「味道墙」，按时间倒序展示所有成品与点评，含评分人。 |
| 手机端用起来顺手吗？ | 三餐卡片在 ≤980px 自动双列、≤640px 自动单列；点菜/管理/点评弹窗均已针对窄屏优化。 |
