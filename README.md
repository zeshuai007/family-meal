# 饭点 · 家庭点菜

面向家庭厨房的响应式点菜系统：家人可以在手机、平板和电脑上安排每日三餐，查看菜谱、上传成品图并留下点评；管理员可以维护家庭菜单。

## 已实现功能

- 今日餐桌：早餐、午餐、晚餐三餐点菜和一键确认
- 菜单浏览：菜品图片、分类、标签、评分、烹饪时间和搜索筛选
- 菜谱详情：主食材、配菜、配料、详细步骤
- 家人点评：评分、点评人展示和成品图上传预览
- 点菜记录：今日菜单确认状态和历史记录
- 菜单管理：管理员权限下添加、编辑、上架和下架菜品
- 数据持久化：点菜、点评、菜单修改保存在浏览器 `localStorage`
- 响应式布局：桌面侧栏、移动端底部导航，适配手机、平板和电脑

## 本地运行

环境要求：Node.js 20.19+。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 部署到 1Panel

1. 在服务器安装 Node.js 20.19+，将项目上传到 1Panel 管理的服务器。
2. 执行 `npm install && npm run build`。
3. 在 1Panel「网站」中创建静态网站，网站目录指向项目的 `dist` 目录。
4. 绑定域名并配置 HTTPS，即可通过手机、平板和电脑访问。

当前版本是无需后端即可部署的家庭版实现，记录保存在每个浏览器本地。若需要多个设备或多个家庭成员共享同一份记录，可在 1Panel 中配合数据库和登录 API，将 `localStorage` 存储层替换为服务端接口。
