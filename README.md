# 一日三餐 · 家庭点菜

一个无需后端即可运行的家庭点菜系统原型，适配手机、平板和电脑。点菜、评分和新菜会通过浏览器 `localStorage` 持久化保存。

## 本地运行

直接用浏览器打开 `index.html`，或在项目目录运行任意静态文件服务器：

```bash
npx serve .
```

## 部署到 1Panel

1. 在 1Panel 创建网站，选择静态网站。
2. 将项目文件上传到网站根目录（`index.html`、`styles.css`、`app.js`）。
3. 设置默认文档为 `index.html`，开启 HTTPS 后即可通过手机访问。

## 功能

- 今日早餐、午餐、晚餐点菜，支持取消和本地持久化记录。
- 家庭菜单搜索、分类筛选，以及管理员添加、上架和下架菜品。
- 添加菜品时支持上传图片，菜品包含食材和详细做法字段。
- 点菜记录支持 5 星点评入口，页面自适应三端布局。
